# Phase 48 — Desktop Application Requirements

## 1. Overview & Scope

Phase 48 delivers the desktop application for OmniBuds, providing an accessible, robust, and hardware-truthful presentation layer for Linux, macOS, and Windows. In strict compliance with the core architectural principle that **OmniBuds never simulates a hardware capability**, the desktop application reflects actual hardware, OS adapter, and shared-core state without inventing unsupported controls, fake battery percentages, or synthetic audio codec configurations.

The desktop presentation architecture is modularized in `:platform:desktop` (depending on `:core` with zero cyclic dependencies) and implements a pure-Kotlin reactive MVVM/MVI presentation model. Because the headless build environment lacks a running display server (X11/Wayland) and offline sandbox policies forbid downloading Compose Multiplatform graphical dependencies, presentation state, view models, navigation, accessibility semantic nodes, and UI renderers are 100% deterministic and unit-testable without a running GUI engine.
