# Phase 34 — Recovery State Machine

## States

IDLE → FAILURE_CLASSIFIED → RECOVERY_PLANNED →
{ WAITING_FOR_PRECONDITION, RETRY_SCHEDULED, RECONNECTING,
  SESSION_RECREATING, STATE_RECONCILIATION } →
{ RECOVERY_SUCCEEDED, RECOVERY_EXHAUSTED, RECOVERY_ABORTED,
  RECOVERY_CANCELLED } → IDLE.

## Legal transitions

- IDLE → FAILURE_CLASSIFIED only.
- FAILURE_CLASSIFIED → RECOVERY_PLANNED | RECOVERY_ABORTED.
- RECOVERY_PLANNED → WAITING_FOR_PRECONDITION | RETRY_SCHEDULED |
  RECONNECTING | SESSION_RECREATING | STATE_RECONCILIATION |
  RECOVERY_ABORTED | RECOVERY_CANCELLED.
- WAITING_FOR_PRECONDITION → RETRY_SCHEDULED | RECONNECTING |
  RECOVERY_ABORTED | RECOVERY_CANCELLED | RECOVERY_EXHAUSTED.
- RETRY_SCHEDULED / RECONNECTING / SESSION_RECREATING →
  FAILURE_CLASSIFIED (another failure) | RECOVERY_SUCCEEDED |
  RECOVERY_EXHAUSTED | RECOVERY_CANCELLED.
- STATE_RECONCILIATION → RECOVERY_PLANNED | RECOVERY_SUCCEEDED |
  RECOVERY_ABORTED | RECOVERY_CANCELLED.
- Terminal states → IDLE only (new episode).

## Forbidden

- Reporting READY from any recovery state.
- A superseded session publishing state.
- Inheriting another device's pending operations.
- Claiming hardware settings restored on reconnect.

## Guards

- Transitions are explicit; illegal ones return false.
- Cancellation forces the CANCELLED terminal.
